# 数字军师 — 企业决策智能系统 产品方案

> 版本：v1.0 | 日期：2026-08-10 | 基于 OntoDB 六模态数据库

---

## 一、产品定位

**一句话定位**：让 CEO 能看清、复盘和传承自己的决策智慧。

**核心价值**：
- **可视**：决策过程透明化，每一步思考、情绪、环境都可追溯
- **可追溯**：任意决策可回溯到原始上下文，支持审计和复盘
- **可传承**：决策模式沉淀为"人格沙盒"，新人可模拟老领导的决策思路

**目标用户**：企业一把手（CEO/总经理）、高管团队、董事会

---

## 二、核心功能模块

### 模块 1：专家决策回溯

**功能**：多模态记录决策者的决策路径，形成可回溯的"认知资产"。

**数据采集**：
- 语音：会议录音 → ASR 转文字 → 情绪分析
- 文本：邮件、IM 聊天、文档批注
- 操作：系统操作日志、审批流程

**存储模型**（基于 OntoDB 六模态）：

| 模态 | 数据 | OntoDB 存储 |
|------|------|------------|
| 关系型 | 决策记录、上下文、结果 | `{Decision}::{id}` |
| 图 | 决策者→部门→项目关系 | GraphStore |
| 向量 | 决策文本嵌入（语义相似度） | HNSW 索引 |
| 时序 | 决策时间线、情绪变化曲线 | TSM 存储 |
| 空间 | 决策发生地点（会议室、出差地） | R*Tree 索引 |
| 本体 | 决策本体（类型、属性、推理规则） | OWL 推理引擎 |

**查询能力**：
```sql
-- 查找CEO在高压力下的战略决策
SELECT * FROM Decision 
WHERE category = '战略' AND pressure_level > 7
ORDER BY decision_date DESC

-- 语义搜索：找到与当前场景相似的历史决策
VECTOR SEARCH ON Decision (embedding) QUERY [当前场景向量] TOP 5

-- 图遍历：追踪决策影响链
GRAPH TRAVERSE FROM 'Decision::D001' OUT LABEL 'affects' DEPTH 3
```

### 模块 2：人格沙盒

**功能**：用历史决策数据模拟决策者面对新问题时的反应和思路。

**技术原理**：
1. **人格特征提取**：从历史决策中提取决策者的特征向量
   - 风险偏好（高风险决策占比）
   - 决策速度（平均响应时间）
   - 数据依赖度（基于数据分析 vs 直觉的比例）
   - 直觉权重（数据不足时的判断倾向）

2. **决策模式学习**：用向量相似度匹配历史相似场景
   - 输入新场景描述 → 生成嵌入向量
   - 在历史决策中搜索最相似的 Top-K
   - 基于相似决策的模式预测可能的决策方向

3. **沙盒模拟**：调整参数观察决策变化
   - 压力参数：模拟不同压力等级下的决策倾向
   - 时间约束：模拟紧急情况下的快速决策
   - 信息完整度：模拟信息不足时的判断

**交互方式**：
```
用户输入: "竞对降价30%，我们是否跟进？"

系统输出:
├── 历史相似决策: 产品定价策略调整 (相似度 82%)
├── 人格特征分析:
│   ├── 风险偏好: 65% (中高)
│   ├── 数据依赖: 70% (重视数据)
│   └── 决策速度: 80% (较快)
├── 模拟决策: 会先分析竞对降价原因和客户反馈，3天内给出应对方案
└── 建议: 参考历史定价调整经验，降价40%是风险收益比最优的选择
```

### 模块 3：决策审计链

**功能**：为高风险决策提供不可篡改的审计线索。

**技术实现**：
- 每条决策记录生成 SHA-256 哈希链
- 决策步骤、情绪数据、环境数据全部纳入哈希链
- 支持事后验证：任何篡改都会导致后续所有记录校验失败

**应用场景**：
- 金融合规：证明决策过程符合监管要求
- 内部审计：追溯重大决策的责任链
- 法律保护：为决策提供"自证清白"的证据

### 模块 4：决策知识图谱

**功能**：构建企业决策知识网络，沉淀组织智慧。

**本体定义**：
```sql
CREATE ONTOLOGY DecisionOntology (
  CLASS Decision,
  CLASS DecisionMaker,
  CLASS DecisionContext,
  CLASS DecisionOutcome,
  
  PROPERTY madeBy DOMAIN Decision RANGE DecisionMaker,
  PROPERTY hasContext DOMAIN Decision RANGE DecisionContext,
  PROPERTY hasOutcome DOMAIN Decision RANGE DecisionOutcome,
  PROPERTY similarTo DOMAIN Decision RANGE Decision TRANSITIVE,
  PROPERTY influences DOMAIN Decision RANGE Decision TRANSITIVE,
  
  -- 推理规则
  CLASS HighRiskDecision SUBCLASS OF Decision,
  CLASS StrategicDecision SUBCLASS OF Decision,
  CLASS CrisisDecision SUBCLASS OF HighRiskDecision
)
```

**推理能力**：
- 查询"所有高风险决策"自动包含"危机决策"
- 查询"影响A决策的因素"自动传递到所有间接影响的决策
- 查询"与当前场景相似的历史决策"利用向量语义搜索

## 四、数据模型

### 核心实体

```sql
-- 决策者
CREATE VERTEX TABLE DecisionMaker (
    name STRING, role STRING, company STRING,
    style STRING,  -- 激进型/稳健型/分析型/直觉型
    avatar_url STRING
);

-- 决策记录
CREATE VERTEX TABLE Decision (
    title STRING, description STRING,
    category STRING,    -- 战略/产品/人事/财务/危机
    priority STRING,    -- P0/P1/P2
    status STRING,      -- 待定/已决策/已执行/已复盘
    decision_text STRING,
    decision_date STRING,
    emotion_state STRING,     -- 冷静/焦虑/兴奋/犹豫
    confidence_score DOUBLE,  -- 0-1
    pressure_level INT,       -- 1-10
    embedding STRING          -- 向量嵌入
);

-- 决策上下文
CREATE VERTEX TABLE DecisionContext (
    decision_id STRING,
    event_type STRING,         -- 市场变化/内部危机/竞对动态/政策变化
    event_detail STRING,
    market_condition STRING,   -- 牛市/熊市/震荡/平稳
    team_morale INT,           -- 1-10
    financial_pressure INT,    -- 1-10
    time_pressure INT          -- 1-10
);

-- 决策结果
CREATE VERTEX TABLE DecisionOutcome (
    decision_id STRING,
    result_type STRING,        -- 成功/部分成功/失败/待评估
    result_detail STRING,
    revenue_impact DOUBLE,     -- 万元
    lesson_learned STRING
);

-- 决策步骤（思维路径）
CREATE VERTEX TABLE DecisionStep (
    decision_id STRING,
    step_order INT,
    thought STRING,
    option STRING,
    reason STRING,
    emotion STRING,
    timestamp STRING
);

-- 人格特征
CREATE VERTEX TABLE PersonalityTrait (
    maker_id STRING,
    trait_name STRING,    -- 风险偏好/决策速度/数据依赖/直觉权重
    trait_value DOUBLE,   -- 0-1
    evidence STRING
);
```

## 五、API 设计

### 决策管理

```bash
# 创建决策
POST /api/decisions
{
  "title": "是否进入政务市场",
  "category": "战略",
  "priority": "P0",
  "context": { "event_type": "政策变化", "pressure_level": 6 }
}

# 添加决策步骤
POST /api/decisions/:id/steps
{
  "thought": "政务市场政策窗口期明确",
  "option": "立即进入/等待观望/找合作伙伴",
  "reason": "窗口期不等人，先占位再补能力",
  "emotion": "冷静"
}

# 记录决策结果
POST /api/decisions/:id/outcome
{
  "result_type": "成功",
  "result_detail": "6个月内签约浙江省公安厅",
  "revenue_impact": 450,
  "lesson_learned": "政务市场需要耐心"
}
```

### 语义查询

```bash
# 语义搜索相似决策
POST /api/vector/search
{
  "class": "Decision",
  "column": "embedding",
  "query_vector": [当前场景向量],
  "top_k": 5
}

# 图遍历决策影响链
POST /api/graph/traverse
{
  "start": "Decision::D001",
  "direction": "out",
  "edge_label": "influences",
  "max_depth": 3
}
```

### 人格沙盒

```bash
# 获取决策者人格画像
GET /api/personality/:maker_id

# 模拟决策
POST /api/simulate
{
  "maker_id": "张明远",
  "scenario": "竞对降价30%，是否跟进",
  "params": { "pressure": 7, "time_constraint": "紧急" }
}
```

## 六、前端界面

### 界面 1：决策时间线
- 时间轴展示所有决策记录
- 点击展开：上下文、思维路径、结果
- 按类别/优先级/状态筛选

### 界面 2：人格沙盒
- 左侧：人格特征雷达图
- 中间：输入场景描述
- 右侧：模拟决策结果 + 历史相似决策

### 界面 3：决策知识图谱
- 力导向图展示决策关系网络
- 节点 = 决策，边 = 影响关系
- 点击节点展开详情

### 界面 4：审计链
- 决策哈希链可视化
- 任意记录可验证完整性
- 导出审计报告
